# L00-T19 Preuve : lecture de TED et de son API de recherche (lignes 3 et 4)

## Ce qu'il faut livrer

Fiche de preuve au gabarit commun écrit dans la fiche L00-T07 (section « Gabarit d'une fiche de preuve », lisible avant que L00-T07 soit faite) pour les lignes 3 et 4 du registre des sources (avis européens TED et leur API de recherche) : méthode réelle de la recherche (aujourd'hui NON VÉRIFIÉE), clé exigée ou non, limite de débit, requête filtrée par codes du marché, pays et date de publication, pagination, volume d'avis sur 24 heures pour la France, champs constatés, forme d'un avis de modification (renvoi vers l'avis initial), d'un avis d'annulation et d'un avis de pré-information, niveau proposé avec relecteur, verdict. Document public : uniquement des noms de champs, des nombres, des codes de réponse, des adresses de points d'accès et des dates ; aucune réponse brute, aucun nom d'acheteur, de ville ni de personne ; réponses brutes jamais commitées : l'auteur cite seulement leur empreinte SHA-256, la date et l'adresse du point d'accès ; le directeur range les copies hors du dépôt public s'il le veut. Lecture seule, sans compte, aucun téléchargement de document de consultation. Refus du relais de la session : « NON PROUVÉ — accès réseau de l'environnement fermé », jamais « refus du site » ; la fiche reste alors faite avec ce constat (repli). Exécution : si la session de l'auteur n'a pas d'accès réseau, le document est écrit quand même avec « NON PROUVÉ — accès réseau de l'environnement fermé » et la mention « à rejouer en CI » ; la preuve réseau se rejoue ensuite dans la CI (lancement à la main, sortie réseau ouverte, données fictives, aucun compte), hors de cette fiche. Les lectures réseau ne se font pas depuis la session : lire la sortie du workflow manuel `preuves-reseau.yml` (lancé par le directeur, données fictives, aucun compte) par `git show origin/preuves/<ID>:preuves-<source>.txt`. Sortie absente : « NON PROUVÉ — sortie du workflow absente (date) ».

## Exigences visées

- R154 : lecture des sources prouvées seulement
- R153 : un niveau se gagne par une preuve

## Cas limites à tester

débit dépassé (arrêt propre) ; page vide ; avis dans une autre langue que le français ; refus du relais de la session.

## Tests

Contrôles de relecture du document (pas de test de code ; chaque ligne est vérifiée par le relecteur, le document ne peut pas être fait sans preuve : il écrit NON PROUVÉ) : « R154 — le document donne, pour les lignes 3 et 4, point d'accès, conditions, rythme, volume, champs constatés et verdict » ; « R153 — le document propose un niveau N1, N2 ou N3 avec un relecteur différent de l'auteur à partir de N2 ».
