# L00-T13 Preuve : deuxième facteur par le Keycloak de la console, repli brique comptes

## Ce qu'il faut livrer

Document : (1) constat lu dans le dépôt public de la console : le royaume `equipe` impose un deuxième facteur (flux `navigateur-equipe`, application d'authentification ou clé d'accès, `acr=mfa`, mappeur `amr`), le royaume `clients` n'en a aucun ; (2) contrat attendu du jeton de session du portail pour les gestes protégés : `acr = mfa` et `auth_time` de moins de 5 minutes (règle de `exiger-reauthentification.ts`) ; `amr` lu en plus seulement si la console l'adopte (demande à la console sur le deuxième facteur), sinon `reauthentification_requise` (code du contrat commun de la console) ; (3) faux serveur de la console qui émet ces jetons (avec, sans, trop vieux, mauvais royaume) : DÉCRIT dans le document (les quatre jetons, leurs champs et la réponse attendue de l'outil pour chacun), PAS codé dans cette fiche ; (4) texte de la demande à la console (deuxième facteur du royaume `clients`) ; (5) repli autonome : l'extension de deuxième facteur de better-auth 1.7.18 marche avec la brique comptes du kit (tables, routes, invitation), sans casser R-C1 à R-C6 ; verdict sur les fichiers de L01-T41. Aucun appel à la console réelle. Lecture permise, en lecture seule, de ces fichiers du dépôt PUBLIC de la console : `ops/socle/keycloak/royaume-equipe.json`, `ops/socle/keycloak/royaume-clients.json`, `packages/contrats/src/commun/erreurs.ts`, `apps/api/src/auth/exiger-reauthentification.ts`. Dépôt public : `https://github.com/will383842/axion-automatisations-clients`, révision lue lors de l'écriture de cette fiche : `b6c66c5`. Commande : `git clone --depth 50 https://github.com/will383842/axion-automatisations-clients <dossier temporaire hors du dépôt>` puis `git -C <dossier> checkout b6c66c5` ; si cette révision n'est plus dans les 50 derniers commits, lire `main` et noter dans le document la révision lue (`git rev-parse --short HEAD`) et les fichiers qui ont changé depuis `b6c66c5`. Si le clone échoue : « NON PROUVÉ ». Ce clone d'un dépôt public est la seule sortie réseau de cette fiche. Le point 5 se fait sur une branche locale jamais poussée ; seul le document est commité.
