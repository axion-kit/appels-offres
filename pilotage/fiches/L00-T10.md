# L00-T10 Preuve : formulaires DC1, DC2, DC4, ATTRI1, DUME et courriers NOTI

## Ce qu'il faut livrer

Document : version en vigueur de chaque formulaire (source datée), champs, possibilité de remplissage sans altérer l'original ; verdict MVP (feuille « valeurs à recopier ») ou plus. Pour NOTI1, NOTI3 et la notification du marché : seulement les champs à lire (délai pour produire les pièces, décision, date), ces courriers venant de l'acheteur et n'étant jamais remplis par l'outil ; la liste des formulaires en vigueur est relue sur la page officielle de la direction des affaires juridiques du ministère de l'Économie, avec la date de consultation, ou « NON VÉRIFIÉ » si la page n'est pas joignable.

## Exigences visées

- R65 : formulaires officiels de candidature

## Cas limites à tester

formulaire en PDF non modifiable ; version périmée ; groupement : un DC1 par entreprise du groupe ; entreprise à plusieurs établissements : le SIRET de l'établissement signataire est celui reporté ; formulaire proposé en deux versions datées (la version en vigueur est citée avec sa date).

## Tests

Contrôles de relecture du document (pas de test de code ; chaque ligne est vérifiée par le relecteur, le document ne peut pas être fait sans preuve : il écrit NON PROUVÉ) : « R65 — le document donne, pour chaque formulaire (DC1, DC2, DC4, ATTRI1, DUME, NOTI), la version en vigueur datée, les champs et le verdict ».
