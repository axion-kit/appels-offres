# L00-T02 Blocs de planche manquants : onglets, case, bouton inactif, liste de pièces

## Ce qu'il faut livrer

Les types de blocs de `ecrans.ts` et leur rendu dans `src/components/EcranVue.tsx` (le moteur de planche du kit ; exception permise par cette fiche) gagnent 5 sortes : `onglets`, `case` (jamais cochée d'avance), `bouton-inactif` (avec sa raison écrite), `liste-pieces` (chaque pièce demandée avec son état et, si elle manque, sa raison), `ligne-etape` (« Étape : … · … »). La carte et le calendrier restent montrés par leur liste équivalente. Aucun écran n'est encore ajouté.

## Exigences visées

- R13 : une chose à la fois
- R24 : aucun bouton mort
- R17 : un seul mot par étape

## Cas limites à tester

case rendue non cochée ; bouton inactif sans raison refusé par le type ; onglets vides (refus) ; écran de 8 blocs (refus) ; liste de pièces de 50 lignes sans débordement ; 7 blocs au plus par écran ; le bloc `case` accepte un libellé qui porte le nom de l'entreprise (« … au nom de <entreprise> ») ; le bloc `bouton-inactif` couvre aussi le bouton secondaire à côté du bouton plein (« Retenir sans commencer ») ; nouveau bloc `ligne-etape` (« Étape : … · … ») ; le rendu d'`EcranVue` ne lit que des variables (`--c-*`, `--couleur-*`) : le même écran rendu avec les deux jeux n'a aucune couleur écrite en dur.

## Tests

`src/design/ecrans-blocs.test.tsx` › « R13 — un écran déclaré refuse plus de 7 blocs et plus d'un bouton plein » ; « R24 — un bouton inactif affiche toujours sa raison » ; `src/design/ecrans-blocs.test.tsx` › « R17 — le bloc ligne-etape affiche l'étape et sa mention » ; « R13 — un écran rendu avec le jeu console puis le jeu bleu v23 ne contient aucune couleur hors des jetons » ; `src/design/ecrans-blocs.test.tsx` › « R24 — un bloc case n'est jamais rendu coché d'avance » ; « R13 — un bloc onglets vide est refusé par le type ».
