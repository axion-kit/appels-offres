# L00-T25 Jetons : types, valeurs des deux jeux et réglage du jeu

## Ce qu'il faut livrer

`src/design/jetons.ts`, première partie : types, valeurs des deux jeux et réglage du jeu. Types `NomJeu`, `Couleurs` (avec `barreActifTexte`, `barreRepere`, `bordureChamp`, `focus`, `etape`), `Jeu` ; objet `jeux` avec le jeu « console » (valeurs du paquet de design de la console, recopiées ci-dessous : clair, sans thème sombre, polices Fraunces, Manrope, Inconsolata) et le jeu « bleuV23 » (second jeu : bleu `#1a4dd9`, menu `#132a4f`, `accentTexte` blanc, `accentFort` `#1846c4`, `barreRepere` `#8fb4ff`, polices Manrope, Inter, Inconsolata, thème sombre proposé) ; `JEU_PAR_DEFAUT = "console"` ; `choisirJeu`, `utiliserJeu`, `themes` du jeu actif. Garder tous les exports actuels du fichier (`couples`, `Couple`, `cssJetons`, `couleursJetons`, `CIBLE_MIN`, `RUPTURE`, `espaces`, `rayons`, `typo`) : `layout.tsx`, `src/lib/design/*` et `src/lib/planche/planche.ts` les importent. La constante `ACCENT` (`#e8730c`), lue seulement à l'intérieur de `jetons.ts`, est retirée avec l'ancien objet `themes` écrit en dur. Dans `couples`, et seulement là, deux couples changent pour que le test de contraste du kit (`src/lib/design/contraste.test.ts`, « tous les couples des jetons passent, en clair comme en sombre ») reste vert avec le jeu console : « texte sur entrée active » devient `avant: "barreActifTexte", fond: "barreActif"` (`#7a2c0d` sur `#ffffff` = 9,57, minimum 4,5) ; « accent sur barre (repère) » devient `avant: "barreRepere", fond: "barre"` (`#ffffff` sur `#9a3812` = 7,12, minimum 3). Les autres couples du kit sont inchangés et passent déjà avec le jeu console (le plus bas : texte du bouton principal, `#ffffff` sur `#c24a1b` = 4,90) et avec le jeu bleuV23, en clair comme en sombre (calcul WCAG du 08/11/2026). `bloc()` ignore la clé `etape` (objet) : aucune ligne `--c-etape` n'est écrite. L00-T01 reprend ensuite la liste complète des couples, le CSS des étapes, les cibles tactiles et la planche. Le jeu « console » est le jeu par défaut ; le bleu v23 est le second jeu, dans le même fichier, choisi par le réglage `AO_JEU_JETONS=bleuV23` en mode autonome seulement.

Deux changements obligatoires dans cette fiche, parce que la clé `etape` est un objet et non une chaîne (sans eux, `src/lib/design/contraste.ts` ne compile plus, et ce fichier n'est pas autorisé ici) :
- (a) `couleursJetons()` ne fait plus `Object.values(...).map((c) => c.toLowerCase())` directement : elle parcourt les clés de chaque thème (clair et sombre) des DEUX jeux, saute la clé `etape`, puis ajoute à part les `fond` et `texte` de chaque étape ; elle rend l'union sans doublon, en minuscules.
- (b) Nouveau type exporté `export type CleCouleur = Exclude<keyof Couleurs, "etape">;` et `export type Couple = { nom: string; avant: CleCouleur; fond: CleCouleur; min: number; seulement?: "clair" | "sombre" };`. Ainsi `c[k.avant]` reste une chaîne dans `controlerCouples` de `contraste.ts`, qui n'est pas modifié. Les couples des étapes ne vont jamais dans `couples` : L00-T01 les met dans une liste à part.

Spécification de `jetons.ts` (première partie) :
```
export type NomJeu = "console" | "bleuV23";
export type Couleurs = { fond; surface; texte; texteDoux; bordure; bordureChamp; barre; barreTexte; barreTexteDoux;
  barreActif; barreActifTexte; barreRepere; accent; accentTexte; accentFort; focus; succes; alerte; erreur;
  etape: Record<"atrier"|"retenu"|"commence"|"avalider"|"envoye"|"resultat"|"ecarte", { fond: string; texte: string }> };
export type CleCouleur = Exclude<keyof Couleurs, "etape">;   // seules clés permises dans Couple.avant et Couple.fond
export type Jeu = { nom: NomJeu; clair: Couleurs; sombre: Couleurs | null; polices: { titre: string; texte: string; code: string } };
export const jeux: Record<NomJeu, Jeu> = { console: {...}, bleuV23: {...} };
export const JEU_PAR_DEFAUT: NomJeu = "console";
/** LE réglage : variable d'environnement AO_JEU_JETONS, lue côté serveur seulement ; mode module => toujours "console". */
export function choisirJeu(reglage = process.env.AO_JEU_JETONS, mode: "module" | "autonome" = modeActif()): NomJeu
// inconnu ou vide => "console" ; "bleuV23" demandé en mode module => "console" et un avertissement `console.warn` au démarrage (aucune ligne d'`historique` ni de `PortJournal`).
export let jeuActif: NomJeu = choisirJeu();
export let themes: { clair: Couleurs; sombre: Couleurs } = …   // jeu actif ; sombre = clair si null (garde la signature lue par src/lib/design/contraste.ts)
export function utiliserJeu(nom: NomJeu): void              // pour la planche et les tests ; remet à jour jeuActif et themes
```
`modeActif()` est une petite fonction locale de `jetons.ts` qui lit `process.env.AO_MODE` (`console` donne `"module"`, toute autre valeur `"autonome"`) ; elle a la même règle que `modeActif()` de `src/lib/console/mode.ts` (L01-T57), sans l'importer.

Règle des couleurs permises (testée) : aucune couleur hors des deux jeux ci-dessus.
- Jeu console : aucun bleu, c'est-à-dire aucune couleur dont la teinte TSL est entre 180° et 250° avec une saturation d'au moins 20 % (le violet de « Validé et envoyé », teinte d'environ 260°, est permis).
- Jeu bleuV23 : aucun des codes `#e8730c`, `#b23f16`, `#d97757`, `#9a3812` (anciens orange et terracotta), sur aucune clé ni dans le sombre ; et aucune teinte orange ou brune, c'est-à-dire aucune couleur dont la teinte TSL est entre 15° et 45° avec une saturation d'au moins 30 %, SAUF `alerte` (clair `#7a4300`, sombre `#e0b04a`) et les deux couleurs de l'étape « À valider » (`#7a4300`, `#fcf5e9`), qui sont la couleur d'alerte et s'affichent toujours avec leur mot.
- La teinte et la saturation se calculent dans le test (petite fonction locale du fichier de test, formule TSL classique), sans dépendance nouvelle.
