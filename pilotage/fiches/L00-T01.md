# L00-T01 Jetons : un fichier, deux jeux (console par défaut, bleu v23 en option)

## Ce qu'il faut livrer

Seconde partie de `src/design/jetons.ts` (le fichier, ses types, ses deux jeux de valeurs et `choisirJeu` / `utiliserJeu` sont livrés par L00-T25 : ne pas les réécrire) : `couples` complétés, `cssJetons(nom)` qui écrit `--c-*` et `--couleur-*`, `couleursJetons()` des deux jeux, `CIBLE_MIN = 44`, `CIBLE_ORDI = 36`, `RUPTURE = 720`, rupture des cibles à 1100 ; `planche-cli.ts` écrit les deux planches `planche/planche-console.html` et `planche/planche-bleu-v23.html`, toutes deux à valider ; `pnpm design:check` vert pour chaque jeu. Le jeu console reste le défaut, le bleu v23 le second jeu, dans le même fichier de jetons.

Suite de la spécification de `jetons.ts` :
```
export const couples: Couple[]                              // ceux du kit + « texte sur entrée active » (barreActifTexte/barreActif, 4,5)
                                                            // + « repère sur barre » (barreRepere/barre, 3) + « focus sur fond » (focus/fond, 3)
                                                            // + « focus sur carte » (focus/surface, 3) + « bordure de champ » (bordureChamp/surface, 3)
                                                            // + un couple par étape (etape.x.texte/etape.x.fond, 4,5)
export function cssJetons(nom: NomJeu = jeuActif): string   // écrit --c-* (kit) ET --couleur-* (noms du paquet de design de la console) ;
                                                            // bloc sombre seulement si jeux[nom].sombre ; color-scheme: light pour "console"
export function couleursJetons(): string[]                  // union des couleurs des DEUX jeux (pour design:check)
```
Variables `--couleur-*` écrites par `cssJetons` (noms du paquet de design de la console) : `--couleur-menu-fond` = `barre` ; `--couleur-menu-texte` = `barreTexte` ; `--couleur-menu-secondaire` = `barreTexteDoux` ; `--couleur-menu-actif-fond` = `barreActif` ; `--couleur-menu-actif-texte` = `barreActifTexte` ; `--couleur-fond-portail` = `fond` ; `--couleur-fond-carte` = `surface` ; `--couleur-bordure-carte` = `bordure` ; `--couleur-bordure-champ` = `bordureChamp` ; `--couleur-texte-principal` = `texte` ; `--couleur-texte-discret` = `texteDoux` ; `--couleur-action` = `accent` ; `--couleur-actionTexte` = `focus` ; `--couleur-lien` = `accentFort` ; `--couleur-etat-urgent-trait` = `erreur`. Pour le jeu console, ces variables ont exactement les valeurs du paquet de la console.

Planche : `planche-cli.ts` fait `for (const nom of ["console", "bleuV23"]) { utiliserJeu(nom); writeFileSync(...) }` avec `construirePlanche()` du kit (qui appelle `cssJetons()` sans argument, donc sur le jeu actif) ; `src/lib/planche/planche.ts` n'est pas touché ; le titre de chaque planche dit son jeu (« Planche de maquettes : jeu console », « Planche de maquettes : jeu bleu v23 ») ; les codes de résultat sont pris sur les deux planches.

## Exigences visées

- R18 : polices et couleurs de la marque
- R20 : des boutons faciles à toucher

## Cas limites à tester

contraste de chaque couple de chaque jeu en clair et en sombre (AA 4,5:1 texte, 3:1 repère, focus et bordure de champ) ; aucune couleur hors de `jetons.ts` ; chaque graisse demandée a son fichier ; le rouge sert à urgent, bloqué et « expirée », toujours avec le mot ; R20 : 44 × 44 px jusqu'à 1100 px de large (téléphone et tablette, cases avec leur libellé et titres de cartes cliquables compris), 36 px de haut au-delà ; jeton de rupture des cibles à 1100 px, distinct de la rupture du menu du kit (720 px, inchangée) ; cohérent avec L01-T31 ; sur ordinateur, jamais moins de 24 × 24 px ; jeu bleuV23 : texte du menu #eef3fa sur le bleu marine (12,8:1), texte du bouton plein blanc sur le bleu (6,8:1) ; une seule couleur d'accent par jeu, celle du bouton plein ; le jeu console reprend tel quel le menu terracotta du paquet de la console (variables `--couleur-*` égales aux valeurs de L00-T25) ; couple dont une couleur est transparente ou mal écrite (refus clair) ; les deux jeux rendus par `cssJetons` ne laissent aucune clé sans variable.
