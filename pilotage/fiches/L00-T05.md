# L00-T05 Planche 3 : Envoi, accusé, résultat, questions, Historique

## Ce qu'il faut livrer

Écrans 15 à 22 (`envoi-confirmer`, `envoi-bloque`, `envoi-moi-meme`, `apres-accuse`, `apres-resultat`, `questions-acheteur`, `historique`, `annulee`) dans cet ordre : « Je confirme l'envoi » d'abord, puis « J'ai envoyé moi-même » ; aucun bouton « forcer ».

## Exigences visées

- R10 : le parcours entier existe dans le MVP
- R58 : pièce obligatoire manquante, l'envoi est bloqué
- R118 : « Je confirme l'envoi » d'abord
- R119 : puis « J'ai envoyé moi-même »

## Cas limites à tester

case non cochée ; pièce manquante nommée ; un seul bouton plein par écran ; nom de fichier sans « xlsx » (mot refusé par le kit) ; libellés de la planche : case « J'ai relu ce récapitulatif et je confirme cet envoi au nom de … » ; « L'ajouter comme personne habilitée » ; pièce manquante avec la seule issue « Cette pièce est fournie autrement » ; « J'ai envoyé moi-même » ABSENT avant la confirmation (R119 fait foi : jamais actif avant la confirmation) ; ligne d'étape « Étape : Commencé · Annulée par l'acheteur » ; états à montrer : paquet de fichiers et sa liste ; rappel 1 h avant ; destinataire ; accusé : empreinte, « à confirmer », liste des fichiers ; version envoyée ; chaque écran est contrôlé sur les deux planches (console, bleu v23) : 0 débordement, contraste AA ; envoi de 12 fichiers : la liste du paquet tient sans débordement à 360 px ; entreprise à deux établissements : l'écran de confirmation nomme l'établissement qui dépose.
