# L00-T23 Preuve : mesure des unités consommées par client, sans aucun prix

## Ce qu'il faut livrer

Document de protocole et d'estimation, fait sans serveur d'essai et sans le code des tâches (aucune dépendance) : méthode de mesure écrite, puis estimation sur pièces fictives de taille connue (unités marquées « estimation »), avec le jeu « Entreprise Exemple », pour trois profils de volume (entité d'une personne, entité moyenne, groupe), le relevé en unités seulement : unités d'IA par tâche (lecture d'annonce, lecture du règlement, brouillon de mémoire, réponse à l'acheteur), octets stockés sous `appels-offres/` et dans `a_appels_offres`, secondes d'exécuteur par tâche, lectures de sources par jour ; méthode de lecture (journal de la passerelle et agrégats de la console en mode console, plafond du kit en mode autonome) ; aucun montant, aucun coût en euros, aucun prix. La mesure réelle sur le site d'essai, avec les vraies tâches, reste « NON PROUVÉE » dans ce document ; elle est refaite avec la même méthode quand le serveur d'essai existe (geste du directeur, hors de cette fiche). Repli : sans la clé d'essai plafonnée fournie par le responsable, la partie « IA réelle » est écrite « NON PROUVÉE » et le relevé se fait avec la fausse IA (unités marquées « estimation »).

## Exigences visées

- R109 : un seul passage vers le fournisseur d'IA
- R195 : sauvegarde et restauration

## Cas limites à tester

fausse IA (unités estimées, marquées « estimation ») ; clé absente (partie « IA réelle » NON PROUVÉE) ; pièce très lourde ; groupe de plusieurs dizaines de personnes.

## Tests

Contrôles de relecture du document (pas de test de code ; chaque ligne est vérifiée par le relecteur, le document ne peut pas être fait sans preuve : il écrit NON PROUVÉ) : « R109 — le document donne le relevé des unités d'IA par tâche, marquées estimation » ; « R195 — le document donne les octets stockés et les secondes d'exécuteur par profil de volume ». Relecture : recherche des motifs d'unité monétaire et du mot prix dans le fichier = 0.
