# L00-T14 Preuve : ouverture des fichiers sans réseau et lecteur indépendant

## Ce qu'il faut livrer

Document fait sans l'outil : un processus séparé, sans réseau ni secret, lit les PDF et les fichiers Word et tableur (texte, nombre de pages, ouverture réussie) ; verdict pour L01-T17, L04-T03 et L06-T02. Repli si ce n'est pas prouvé : contrôles sûrs du code seulement (vrai type, PDF lisible, archive saine, taille). Si aucun processus sans réseau n'est possible dans la routine, écrire NON PROUVÉ et le dire dans la PR.

## Exigences visées

- R95 : fichiers qui s'ouvrent
- R170 : fichiers piégés

## Cas limites à tester

fichier qui tente une connexion ; fichier très lourd ; archive démesurée.

## Tests

Contrôles de relecture du document (pas de test de code ; chaque ligne est vérifiée par le relecteur, le document ne peut pas être fait sans preuve : il écrit NON PROUVÉ) : « R95 — le document dit si un processus sans réseau ouvre les PDF, Word et tableurs » ; « R170 — le document dit ce qui se passe pour un fichier qui tente une connexion ou une archive démesurée ».
