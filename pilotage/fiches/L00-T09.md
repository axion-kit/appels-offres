# L00-T09 Preuve : préremplissage Word et tableur en gardant formules et verrous

## Ce qu'il faut livrer

Document : essai, sur des fichiers fictifs fabriqués, d'une bibliothèque candidate (licence notée) : formules, onglets, verrous gardés ou non ; PDF au texte sélectionnable. Verdict : promis au MVP ou repli « valeurs à recopier ». L'essai se fait dans un dossier temporaire HORS du dépôt (`cd $(mktemp -d) && npm init -y && npm install docx@9.15.2 exceljs@4.4.0`), jamais dans `package.json`. Les fichiers fictifs sont fabriqués par ces bibliothèques elles-mêmes (formule `=SOMME(A1:A3)`, onglet verrouillé), puis relus par fflate (XML brut) pour constater ce qui est gardé. Si l'installation échoue : « NON PROUVÉ ».

## Exigences visées

- R68 : tableau de prix au format de l'acheteur
- R91 : fichiers modifiables et PDF

## Cas limites à tester

fichier avec macros (jamais exécuté) ; cellule fusionnée ; formule externe ; tableur de 10 000 lignes préparé sans dépasser la mémoire permise.

## Tests

Contrôles de relecture du document (pas de test de code ; chaque ligne est vérifiée par le relecteur, le document ne peut pas être fait sans preuve : il écrit NON PROUVÉ) : « R68 — le document dit si formules, onglets et verrous sont gardés au préremplissage d'un tableau de prix, avec le verdict MVP ou le repli « valeurs à recopier » » ; « R91 — le document dit comment un fichier modifiable et un PDF sont remplis ou lus sans altérer l'original ». Condition de L06-T03.
